## Установка
1. клонируйте репозитарий 
git clone https://github.com/AlexVT76/Skypro-homework
2. установите зависимости 
pip install -r requirements.txt
## Использование:

### файл masks.py содержит функции маскировки номера счета и номерв карты
### файл widget.py содержит функции обработки данных
### файл processing.py содержит функции фильтрации и сортировки данных
### файл generators.py содержит функции создания итераторов и генераторов
### файл utils.py содержит функцию чтения  JSON-файла
### файл external_api содержит функцию конвертации валюты в рубли
### файл transaction_reader содержит функцию считывания данных csv и xlsx форматах
